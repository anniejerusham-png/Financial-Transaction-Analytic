# FinSight Data Dictionary

| Column | Description |
|---|---|
| `transaction_id` | Unique synthetic transaction identifier |
| `transaction_date` | Transaction date/time |
| `customer_id` | Synthetic customer identifier |
| `customer_segment` | Customer segment |
| `merchant_category` | Merchant category |
| `payment_method` | Payment channel |
| `city` | Transaction city |
| `transaction_amount_inr` | Transaction amount in INR |
| `transaction_status` | Success, Failed, or Pending |
| `fraud_flag` | Synthetic suspicious-activity indicator |
| `transaction_month` | Reporting month |

**The dataset is synthetic and contains no real customer, bank, card, or payment information.**
