# FinSight — Financial Transaction & Risk Analytics Dashboard

Interactive portfolio dashboard built with HTML, CSS, JavaScript and Chart.js.

## Dataset
The current version uses a **synthetic financial transaction dataset** created for educational portfolio analysis. It does not contain real banking or customer information.

## Dashboard
The dashboard covers:
- transaction value and volume
- monthly trends
- transaction status
- merchant-category performance
- payment-method mix
- geographic transaction value
- customer-segment analysis
- synthetic suspicious-activity indicators

## Live deployment
This project is designed for GitHub Pages. After uploading the repository, enable:
**Settings → Pages → Deploy from branch → main → / (root)**.

The resulting site can be linked from a resume.
