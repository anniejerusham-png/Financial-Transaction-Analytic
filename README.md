# FinSight — Financial Transaction & Risk Analytics

### SQL • Python • Interactive Dashboard

FinSight is a financial transaction analytics project built to explore transaction performance, customer behavior, payment-method trends, and synthetic risk indicators through data analysis and interactive visualization.

## 🚀 Live Dashboard

**[View the Interactive FinSight Dashboard](https://anniejerusham-png.github.io/Financial-Transaction-Analytic/)**

## 🎯 Project Objective

The goal of this project is to transform transaction-level data into business insights that can support financial performance monitoring and risk analysis.

The analysis focuses on:

- Transaction volume and value trends
- Merchant-category performance
- Payment-method behavior
- Geographic transaction activity
- Customer-segment performance
- Transaction success and failure rates
- Synthetic suspicious-activity indicators

## 🔎 Analytical Questions

The project investigates questions such as:

1. How does transaction value change over time?
2. Which merchant categories generate the highest transaction value?
3. Which payment methods have the highest failure rates?
4. Which cities contribute the most transaction value?
5. Which customer segments generate the highest value?
6. Which merchant categories show higher synthetic suspicious-activity rates?
7. Which transactions represent unusually high transaction values?

## 🧪 Dataset

The project uses a **synthetic financial transaction dataset** created for educational and portfolio analysis.

The dataset contains transaction-level attributes including transaction date, customer segment, merchant category, payment method, city, transaction amount, transaction status, and a synthetic suspicious-activity indicator.

**No real customer, bank, card, or payment information is used.**

## ⚠️ Limitation

The suspicious-activity indicator is synthetic and is intended only for demonstrating analytical workflows. It is **not a production fraud-detection, AML, or banking decision model**.
